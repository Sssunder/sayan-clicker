# 🐾 Кот Саян — уютный кликер с задачками

Маленькая игра-перерыв для школьников: гладь кота Саяна, копи лапки, лови вкусняшки
и решай короткие математические задачки на +30 лапок. Работает на Windows, ничего
устанавливать не нужно — один файл `SayanClicker.exe`.

## Скачать и запустить (30 секунд)

1. Открой [страницу релизов](https://github.com/Sssunder/sayan-clicker/releases) и скачай `SayanClicker.exe`.
2. Положи файл в любую папку (например, «Рабочий стол») и дважды кликни по нему.
3. Если Windows покажет синее окно «SmartScreen», нажми «Подробнее» → «Выполнить в любом случае».
   Игра не требует интернета и ничего не отправляет в сеть.

Python и другие программы не нужны.

## Как играть

- **Клик по коту** или **Пробел** — погладить, +лапки. Серия кликов копит комбо и множитель.
- **📐 Задачка** (или клавиша **Q / Й**) — попросить пример прямо сейчас. Верный ответ = +30 лапок.
  Отвечать можно мышью или клавишами **1 / 2 / 3**.
  Ошибся — игра покажет правильный ответ с объяснением, без штрафов.
- **Рыбка на сцене** — кликни по ней, пока не уплыла: бонусные лапки.
- **Тыгыдык** — когда шкала ⚡ заполнится, кот побежит и лапки будут капать x3.
- **🏅** в шапке — сохранить карточку достижения (PNG): имя, уровень, лапки, комбо, дата.
- **📌 Поверх** — окно поверх других, **🪟 Компакт** — маленький режим «между уроками»
  (задачки работают и в нём), **🌙 Кибер-Кот** — ночная тема, **🔊** — тихие звуки вкл/выкл.
- **📷 Своё фото** — можно поставить своего кота вместо Саяна (фото остаётся только на этом компьютере).
- **Правый клик по счёту лапок** → «Начать заново (новый ученик)» — обнуляет прогресс
  (с подтверждением), имя и настройки сохраняются. Удобно, когда за компьютером новый ученик.

## Как подписать карточку именем

Кликни по заголовку **«🐾 Кот Саян»** в окне игры и впиши имя — оно появится на всех
новых карточках. Имя хранится только на этом компьютере.

## Как прикрепить карточку на доску (Miro / Padlet / meleto)

1. Нажми **🏅** — откроется папка с готовой карточкой `sayan-card_….png`.
2. Перетащи PNG прямо на доску (или «Загрузить изображение» в Padlet/Miro).
3. Готово: на доске видно имя ученика, уровень и число лапок — можно устроить «стену достижений» класса.

Карточки лежат в `%APPDATA%\SayanClicker\cards` — их можно собрать в конце недели и раздать родителям.

## Идеи для учителя

- **Разминка на 5 минут**: попроси класс открыть компактный режим и решить 3 задачки (Q) —
  кто быстрее наберёт лапки, тот и молодец; карточки — на доску.
- **Стена достижений**: раз в неделю собирай 🏅-карточки учеников на одну доску.
- Игра не наказывает за ошибки: неверный ответ показывает разбор — это тренажёр, а не контрольная.

## Приватность

Всё сохраняется локально (`%APPDATA%\SayanClicker\save.json`): счёт, настройки, имя.
Своё фото не покидает компьютер. Интернет игре не нужен.

## Для разработчиков

Python 3.10+, PySide6. Запуск: `python main.py`. Тесты: `python -m unittest discover -s tests`.
Сборка exe: `pyinstaller SayanClicker.spec`. Подробности изменений — в [CHANGELOG.md](CHANGELOG.md).
